# Communication & Workflow Rules

- **Direct and Concise**: Keep explanations brief, clear, and actionable. No unnecessary long status messages.
- **Zero Unsolicited Background Tasks**: Never launch browser subagents, long background scans, or unrelated deep dives unless explicitly requested by the user.
- **Targeted Code Changes**: Focus directly on the exact files and lines pertinent to the user's immediate request.
- **Confirm Before Deviation**: Never work on tasks or explore codebase areas beyond what the user asked for.
